# cadapan_mobprog

A Flutter news feed built for a Mobile Programming lab. The feed displays two
sample posts and shows an attached image when a post has one.

The post “Another productive day at school!” uses the bundled
[`school_day.jpg`](assets/images/school_day.jpg) image.

## Run locally

Open the project in VS Code with Flutter 3.47.9 or a compatible Flutter SDK.
Start an Android emulator, then run:

```sh
flutter pub get
flutter run
```
